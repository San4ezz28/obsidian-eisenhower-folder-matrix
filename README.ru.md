# Eisenhower Folder Matrix — плагин для Obsidian

**Бета-версия 0.1.4. Пока не опубликована в официальном каталоге.**

Плагин строит матрицу Эйзенхауэра 2×2 в переносимой Markdown-заметке. Задачи остаются обычными чекбоксами в существующих `.md`-файлах; обязательных тегов, дат и ручной разметки не требуется.

## Основные возможности

- Источник: выбранная папка с опциональными подпапками **или один Markdown-файл**.
- Четыре квадранта, «Входящие» и сворачиваемый раздел «Сделанное».
- Синхронизация выполнения с исходной заметкой в обе стороны, сохранение прежнего квадранта при восстановлении.
- Поддержка задач в callout, Markdown-ссылок, выделения и вложенных списков.
- Настройка показа подзадач: отдельно / внутри родителя / не показывать (выполненные всё равно видны в «Сделанном»).
- Перетаскивание задач и меню `⋯ → Переместить` для телефона.
- **Русский и английский**: «Настройки матрицы → Язык интерфейса»: Автоматически (язык Obsidian) / Русский / English. Настройка сохраняется прямо в файле матрицы, поэтому передаётся через FIT.
- В новых заметках появляется свёрнутый `> [!info]-` callout с подсказкой.

## Как обновить с 0.1.3

Сначала сделай резервную копию хранилища. Закрой Obsidian, замени файлы `main.js`, `manifest.json`, `styles.css` в `.obsidian/plugins/eisenhower-folder-matrix/`, затем запусти приложение. Старые `.md`-матрицы не нужно пересоздавать: поле `language` по умолчанию равно `auto`.

Если в существующей матрице сохранилась старая фиолетовая цитата или подсказка отсутствует, открой эту заметку и вызови команду **«Добавить или обновить callout-подсказку матрицы»**. Она меняет только подсказку активной матрицы; сам JSON и приоритеты не затрагивает.

## Разработка в Cursor

Инструкция — [CURSOR_SETUP.md](CURSOR_SETUP.md); правила для ИИ-агента — [AGENTS.md](AGENTS.md).

```bash
npm install
npm test
npm run build
```

**FIT:** синхронизирует Markdown-файлы задач и матриц, но файлы установки плагина нужно поставить на телефон отдельно. Для тестовых обновлений после публикации на GitHub удобен BRAT. Не загружай в публичный репозиторий личный vault.

Проверка реальных мобильных устройств и конфликтов FIT ещё требуется. Публикация запланирована, но не состоялась.
